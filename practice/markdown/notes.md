# Neovim Markdown 연습 노트

<!-- 연습 키: 제목 위에서 <leader>mf로 섹션 접기, <leader>mF로 펼치기를 연습한다. -->

이 문서는 Markdown 전용 이동, 접기, 링크 이동, 표 편집을 연습하기 위한 파일이다.
백틱 키는 tmux 리더 키이므로 이 연습에서는 백틱 기반 mark 이동을 사용하지 않는다.

## 오늘의 연습 항목

<!-- 연습 키: 체크박스 줄에서 visual selection, indent, surround를 연습한다. -->

- [ ] 제목 사이 이동을 연습한다.
- [ ] 링크를 따라가고 다시 돌아온다.
- [ ] 표 안에서 열 정렬을 확인한다.
- [ ] 시각 모드로 문장을 선택한 뒤 surround를 적용한다.

## 표 편집 연습

<!-- 연습 키: 표 안에서 행을 추가하고 :TableModeRealign으로 정렬을 확인한다. -->

| 기능 | 파일 | 확인할 동작 |
|---|---|---|
| LSP hover | Python, C++ | 심볼 위에서 타입과 설명을 확인한다 |
| DAP | Python | 중단점에서 변수 값을 확인한다 |
| surround | 모든 파일 | 괄호와 따옴표를 빠르게 바꾼다 |
| mkdnflow | Markdown | 링크 이동과 접기를 연습한다 |

## 긴 문단 리팩터링 연습

<!-- 연습 키: 이 문단에서 vip로 문단 선택, gc로 주석 토글, surround로 따옴표/괄호 감싸기를 연습한다. -->

이 문단은 일부러 조금 길게 작성했다. 문장 단위 이동, 줄 바꿈, 검색, 치환,
시각 모드 선택, 들여쓰기 조정, fold 동작을 확인하기 위해 사용한다. 필요하면
문장을 둘로 나누거나 목록으로 바꾸면서 편집 동작을 연습한다.
